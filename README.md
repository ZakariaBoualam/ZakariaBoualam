## 🧑‍💻 À propos de moi

Je conçois des applications web complètes en **PHP procédural** et **MySQL**, avec une
règle simple : **aucune dépendance externe**. Pas de framework, pas de CDN, pas de
`npm install`. Tout est écrit à la main — du moteur de rendu au back-office.

Ce choix n'est pas un caprice. C'est ce qui m'oblige à comprendre ce qui se passe entre
la requête HTTP et la ligne affichée : sessions, requêtes préparées, échappement HTML,
transactions, cycle requête/réponse.

- 🇫🇷 Basé au Maroc
- 🛠️ PHP · MySQL · HTML5 · CSS3 · JavaScript (ES5)
- 🎯 Ce que j'approuve : du code lisible, honnête, et documenté — **y compris ses limites**

## 🚀 Projets

### 🛒 [FreshMart](https://github.com/ZakariaBoualam/FreshMart) — Boutique e-commerce

Site e-commerce complet : catalogue de 90 produits, panier en session, carnet d'adresses,
checkout, historique de commandes, et un back-office de 10 pages.

| | |
|---|---|
| **Stack** | PHP · MySQLi · JavaScript ES5 · CSS Grid |
| **Volume** | 28 fichiers PHP, ~2 030 lignes, 6 tables, 126 lignes de données de démo |
| **Particularité** | Panier en `$_SESSION`, totals recalculés **côté serveur** |
| **Back-office** | Tableau de bord, gestion des commandes, produits avec **upload d'image** |

→ [Voir le dépôt](https://github.com/ZakariaBoualam/FreshMart)

### ∑ [MathBoard](https://github.com/ZakariaBoualam/MathBoard) — Plateforme de maths avec tableau blanc

Cours + exercices + **tableau blanc `<canvas>` sauvegardable**. L'élève résout, ferme
l'onglet, revient : son tableau est exactement là où il l'avait laissé.

| | |
|---|---|
| **Stack** | PHP · **PDO** · JavaScript ES5 · **Canvas 2D** |
| **Volume** | 16 fichiers, ~1 300 lignes, 4 tables, 5 cours, 12 exercices |
| **Particularité** | Annuler/rétablir par instantanés PNG (20 étapes), raccourcis clavier |
| **Sécurité** | Requêtes préparées à 100 %, échappement systématique, `session_regenerate_id` |

→ [Voir le dépôt](https://github.com/ZakariaBoualam/MathBoard)
